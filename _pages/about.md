This study is about empirically evaluating the functional accuracy and the quality of the software code generated by Artificial Intelligence (AI) / Generative Pre-trained Transformers (GPT). Code generated through AI may syntactically and functionally look plausible, but the question is, "are they accurate ?". In order to explore on this, the code generated through AI needs to be quantitatively evaluated through various techniques. One way is to run unit tests againsts the AI code and to assess the test case pass rate and the pass@k rate. Alongside with this, the AI code needs to be reviewed by industry level senior human developers with the touch points such as using best practices, security and maintainability. Code review needs to be stored through a 7 point Linkert scale, and the results must be evalued with descriptive statics.
